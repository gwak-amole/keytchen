# Keytchen
Keytchen is a digital experience where you get to explore a kitchen using eccentric controls, whether on your NanoKEY2 (what this game is intended for) or just your computer keyboard (which works just as well!) This was just a fun project to work on because I wanted to created a game that went beyond the standard WASD/arrow key controls.
